## 🚀 Cómo Ejecutar la Aplicación

### Opción 1: Verla inmediatamente en tu navegador (Sin instalar nada)
Haz doble clic sobre el archivo [`index.html`](index.html). Se abrirá directamente en tu navegador con todas sus funciones operativas (calculadora en tiempo real, simulador de IA y modal de pago a Binance).

### Opción 2: Correr con Node.js Local
En esta carpeta, ejecuta:
```bash
node server.js
```
Abre tu navegador en `http://localhost:3000`.

### Opción 3: Publicar Gratis en la Nube ($0 Costo en Vercel)
1. Puedes arrastrar esta carpeta directamente a [Vercel](https://vercel.com) o vincularla a un repositorio de GitHub.
2. La web quedará alojada en una URL pública global 24/7 disponible para cualquier usuario de internet.
3. Cada usuario que decida desbloquear la Suite Pro pagará directamente a tu **Binance UID: 1049392123**.
